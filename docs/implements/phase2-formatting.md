# Phase 2: 整形

## ゴール

文字起こし結果に対して、ローカルルール整形とLLM整形の2段階整形を適用する。
LLMはタイムアウト・フォールバック付きで、体験を止めない設計にする。

---

## TDD方針

- `LocalFormatter` はルールベースなのでユニットテストを厚くする（入力→期待出力のパターン網羅）
- `LLMFormatter` はHTTP通信をモック化し、タイムアウト/エラー系のテストを重点的に書く
- フォールバック（LLM失敗→ローカル整形で続行）の結合テストを必ず書く

---

## タスクリスト

### 2-1. LocalFormatter（ルール整形）

- [ ] **テスト**: 文頭・文末の不要な空白が除去されることを検証
- [ ] **テスト**: 連続する空白が1つに正規化されることを検証
- [ ] **テスト**: フィラー（「えーと」「あの」「まあ」等）が除去されることを検証
- [ ] **テスト**: フィラー除去で文意が壊れないケースを検証（「あのね」は残す等）
- [ ] **テスト**: 句読点の正規化が動作することを検証（例：「。。」→「。」）
- [ ] **テスト**: 不要な改行が除去されることを検証
- [ ] **テスト**: 空文字列入力に対して空文字列が返ることを検証
- [ ] **テスト**: 整形ルールが固有名詞・数値を変更しないことを検証
- [ ] **実装**: `LocalFormatter` を実装
  - 空白正規化
  - フィラー除去（パターンリスト方式）
  - 句読点正規化
  - 改行正規化
  - 全ルールをパイプラインで順次適用

### 2-2. LLMFormatter（LLM整形）

- [ ] **テスト**: APIリクエストが正しいフォーマットで送信されることを検証（モック）
- [ ] **テスト**: APIレスポンスから整形テキストが正しく抽出されることを検証
- [ ] **テスト**: タイムアウト（2〜3秒）で `LLMFormatterError.timeout` が返ることを検証
- [ ] **テスト**: APIエラー時に `LLMFormatterError.apiError` が返ることを検証
- [ ] **テスト**: 2000文字超の入力でスキップされることを検証
- [ ] **テスト**: プロンプトに制約が含まれていることを検証（意味変更禁止、固有名詞保持等）
- [ ] **テスト**: レスポンスが整形テキストのみ（説明なし）であることを検証
- [ ] **実装**: `LLMFormatter` を実装
  - Gemini Flash API呼び出し（`URLSession`）
  - システムプロンプト：意味変更禁止、固有名詞/数値/専門用語保持、出力は整形後テキストのみ
  - タイムアウト設定（デフォルト2.5秒）
  - 文字数上限チェック（2000文字）
  - エラーハンドリング（タイムアウト、APIエラー、パース失敗）

### 2-3. LLMFormatter のプロンプト設計

- [ ] **テスト**: 「今日は2024年1月1日です」が日付を変えずに返ることを検証
- [ ] **テスト**: 「田中太郎さんに連絡してください」が人名を保持して返ることを検証
- [ ] **テスト**: 技術用語（API, GitHub, TypeScript等）が保持されることを検証
- [ ] **実装**: プロンプトテンプレートの定義
  - モード別プロンプト（memo, email, minutes, bulletPoints）
  - 共通制約（意味変更禁止、固有名詞保持、整形テキストのみ出力）

### 2-4. フォールバック機構

- [ ] **テスト**: LLMタイムアウト時にローカル整形結果が使用されることを検証
- [ ] **テスト**: LLM APIエラー時にローカル整形結果が使用されることを検証
- [ ] **テスト**: LLMスキップ時（2000文字超）にローカル整形結果が使用されることを検証
- [ ] **テスト**: LLM整形OFF時にローカル整形のみ適用されることを検証
- [ ] **テスト**: フォールバック発生時に「整形スキップ」通知が発行されることを検証
- [ ] **実装**: `VoiceInputService` に整形パイプラインを組み込む
  - ローカル整形 → LLM整形（ON時のみ） の順序
  - LLM失敗時はローカル整形結果をそのまま挿入に渡す
  - フォールバック通知の発行

### 2-5. 設定UI

- [ ] Settings画面にLLM整形ON/OFFトグルを追加
- [ ] Settings画面にモデル選択（現時点はGemini Flashのみ）を追加
- [ ] Settings画面にタイムアウト設定（デフォルト2.5秒）を追加
- [ ] Settings画面にAPIキー入力欄を追加（Keychainは Phase 3）
- [ ] メニューバーにLLM整形ON/OFFトグルを追加
- [ ] メニューバーにモード切替（memo / email / minutes / bulletPoints）を追加

## Definition of Done (DoD)

- [ ] `LocalFormatter` がフィラー除去・空白正規化・句読点正規化を実行できる
- [ ] `LocalFormatter` のユニットテスト（各ルールのパターン）が全てグリーン
- [ ] `LLMFormatter` がGemini Flash APIを呼び出し、整形テキストを返せる
- [ ] `LLMFormatter` のタイムアウト（2.5秒）が機能し、超過時にエラーを返す
- [ ] 2000文字超の入力でLLM整形がスキップされる
- [ ] LLM整形失敗時にローカル整形結果で自動フォールバックし、体験が止まらない
- [ ] フォールバック発生時に「整形スキップ」通知が表示される
- [ ] LLM整形ON/OFFがSettings/メニューバーから切り替えられる
- [ ] モード切替（memo等）がメニューバーから選択できる
- [ ] 全テストがグリーン（`xcodebuild test` が成功する）
