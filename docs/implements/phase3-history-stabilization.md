# Phase 3: 履歴・安定化

## ゴール

履歴機能、Keychain によるAPIキー管理、エラーハンドリング強化、全体の安定化を行い、MVPを完成させる。
このフェーズ完了時点で仕様書の受け入れ条件をすべて満たす。

---

## TDD方針

- `HistoryStore` はファイルI/Oをモック化してユニットテスト
- `KeychainHelper` はKeychainアクセスをモック化してユニットテスト
- エラーハンドリングは異常系テストケースを網羅的に書く
- 安定化フェーズではリグレッションテストを強化

## Definition of Done (DoD)

### 機能面
- [x] 直近10件の履歴が保存・表示・再コピーできる
- [x] APIキーがKeychainに安全に保存・読み込みできる
- [x] Settings画面で全設定項目（ホットキー、LLM、APIキー、権限）が操作できる
- [x] 権限不足時にユーザーが迷わず有効化できる導線がある

### 品質面
- [x] 全エラーケースで適切な通知が表示され、アプリがクラッシュしない
- [ ] 連続20回以上の使用でメモリリークがない（※手動テスト）
- [x] 破損データ読み込み時にクラッシュしない
- [x] 全テストがグリーン（`xcodebuild test` が成功する）— 103テスト

### MVP受け入れ条件（仕様書準拠）
- [x] ホットキー押下中録音 → 解除で日本語文字起こしされる
- [x] LLM整形ON/OFFが動作し、ON時も意味が変わらない（固有名詞が壊れない）
- [ ] 複数アプリ（メモ、ブラウザ、Slack等）で貼り付け入力が安定して動く（※手動テスト）
- [x] 権限不足時に、ユーザーが迷わず有効化できる導線がある
- [x] 直近履歴から再利用できる
- [x] 体感遅延：録音終了から挿入まで目標1〜2秒（LLMタイムアウト時はローカル整形で続行）
